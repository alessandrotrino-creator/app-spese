# Gestione Spese - PWA Android App

Repository per l'app di gestione e tracciamento delle spese personali.

## Struttura
- `index.html`: Interfaccia principale e logica dell'app.
- `sw.js`: Service Worker per l'uso offline.
- `manifest.json`: Configurazione per l'installazione su dispositivi mobili.
- `claude.md`: Documentazione del progetto.

## Pubblicazione su GitHub Pages
1. Carica questi file in un repository pubblico su GitHub.
2. Attiva GitHub Pages dalle impostazioni del repository (`Settings` > `Pages` > seleziona il ramo `main`).
3. Apri il link dal tuo smartphone con Chrome e premi "Aggiungi a schermata Home".
